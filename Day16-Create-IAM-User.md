# ☁️ Day 16 – Create IAM User
---
## 📌 Challenge Description

The objective of this task was to create a new IAM user to enable secure and controlled access to AWS resources.

IAM users represent individual identities for managing authentication and authorization.

---

## 🎯 Objective

- Create a new IAM user.
- Configure login access.
- Assign permissions appropriately.
- Validate successful user creation.

---

## 🧠 Key Concepts Learned

### ✅ What is IAM?

Identity and Access Management (IAM) is used to manage:
- Users
- Groups
- Roles
- Permissions
- Access policies

---

### ✅ What is an IAM User?

An IAM user represents a person or service that needs access to AWS.

Each user has:
- Unique credentials
- Individual permissions
- Audit trail

---

### ✅ Authentication Methods

IAM users can authenticate using:
- AWS Console (username + password)
- Programmatic access (Access Key + Secret Key)

---

### ✅ Authorization via Policies

Permissions are assigned using policies that define allowed actions.

---

### ✅ Security Best Practices

- Enable least privilege access.
- Use strong passwords.
- Rotate access keys.
- Avoid root account usage.

---

## ❌ Issues and Learning

- Verified username consistency.
- Assigned only required permissions.
- Understood difference between user and role.

---

## ✅ How the Task Was Completed

- Logged into AWS Console.
- Navigated to IAM → Users.
- Created a new user.
- Configured login access.
- Assigned required permissions.
- Verified user creation.

---

## 🔍 Verification Summary

- IAM user created successfully.
- User login works correctly.
- Permissions assigned properly.

---

## 💡 Key Takeaways

- IAM controls security access.
- Users should follow least privilege.
- Identity management is critical for governance.
- Audit trails improve accountability.
